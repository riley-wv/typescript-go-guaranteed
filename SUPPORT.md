# Support

Use GitHub issues for reproducible bugs, crashes, behavior differences, and release problems:

https://github.com/riley-wv/typescript-go-guaranteed/issues

Before opening an issue:

- Search existing issues.
- Include the `@ts-guaranteed/tsgo` version.
- Include your OS, CPU architecture, Node.js version, and package manager.
- Include a minimal reproduction when possible.

For TypeScript language questions that are not specific to this fork, use the broader TypeScript community resources such as Stack Overflow or the TypeScript Discord.
